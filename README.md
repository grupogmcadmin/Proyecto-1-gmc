# SIGE — paquete PWA inicial corregido
Sube el contenido de esta carpeta a la raíz del repositorio GitHub, conservando exactamente los nombres. Luego configura GitHub Pages en Settings → Pages, rama principal y carpeta raíz.

Este paquete es un prototipo de interfaz instalable. No incluye autenticación, permisos, base de datos empresarial ni sincronización en la nube. No almacenar información sensible ni datos reales hasta implementar un backend seguro.
